# mblt-model-arxiv

Code to reproduce Model results on Mobilint NPUs, from compile to evaluation.
Browse each Model's performance on the [Mobilint Model Zoo](https://zoo.mobilint.com/aries-rb/models/).

- `models/<task>/<Model>/`: one Model's export, calibration, compile, evaluation, and inference
  code. Model folders are independent of each other; each folder's `README.md` has the
  reproduction steps and the expected result.
- `datasets/<Dataset>/`: a `prepare.py` that prepares one dataset, and the
  `dataloader.py`, `evaluator.py`, and `score.py` that score predictions against it.
  Dataset folders are independent of each other too.

A Model folder uses the Dataset folders listed next to it below. Only code is included;
the checkpoint, the dataset, and the Mobilint SDK are not. The code in this repository is
under the BSD 3-Clause license (`LICENSE`); each Model's checkpoint and dataset keep their
upstream license. The folder structure and the dependency rules between folders are in
[`ARCHITECTURE.md`](ARCHITECTURE.md).

Before using qbcompiler 1.4.0 or 1.4.1, read the [SDK 1.4 compatibility notice](SDK_1.4_COMPATIBILITY.md)
for the 102 Models whose configurations are rejected and guidance to use the recorded SDK.
